# shadijhade's Scoop bucket

Install [Glint](https://github.com/shadijhade/glint):

```powershell
scoop bucket add shadijhade https://github.com/shadijhade/scoop-bucket
scoop install shadijhade/glint
```


Install [LogLens](https://github.com/shadijhade/loglens):

```powershell
scoop bucket add shadijhade https://github.com/shadijhade/scoop-bucket
scoop install shadijhade/loglens
```
